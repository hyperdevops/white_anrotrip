# Корпоративная страница (архив)

Черновик `/corp` — **не входит в сборку** и не публикуется на anrotrip.ru.

- `corp.astro` — страница коммерческого предложения
- `assets/` — изображения, привязанные только к этой странице

Чтобы вернуть маршрут: перенести `corp.astro` в `src/pages/` и обновить импорты компонентов/ассетов.
